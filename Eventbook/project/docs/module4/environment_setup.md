# Настройка рабочей среды разработки (Environment Setup)

## 1. Выбранный стек и IDE
* **Язык программирования:** Python 3.11
* **Фреймворк:** FastAPI 0.110 + SQLAlchemy 2.0
* **IDE:** Visual Studio Code (VS Code)

## 2. Установленные расширения VS Code
* **Python & Pylance** — подсветка синтаксиса, автодополнение и статическая проверка типов.
* **Ruff** — автоматическое форматирование при сохранении (`editor.formatOnSave: true`) и подсветка ошибок линтера в реальном времени.
* **Docker** — управление контейнерами и проверка синтаксиса `Dockerfile`.
* **GitLens** — визуализация истории коммитов и веток.

## 3. Стандартизация и Git-хуки
* Настроен единый стиль отступов (4 пробела, UTF-8, LF) через файл `.editorconfig`.
* Конфигурация линтера и форматтера зафиксирована в `pyproject.toml` (максимальная длина строки — 88 символов).
* Установлен инструмент `pre-commit` (`.pre-commit-config.yaml`). При каждой попытке выполнить `git commit` автоматически запускаются `ruff` и `ruff-format`. Коммит блокируется при наличии неразрешенных ошибок стиля или синтаксиса.
