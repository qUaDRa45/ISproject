# Функциональные требования (Functional Requirements)

## 1. Управление мероприятиями и слотами (Events)
* **FR-1.1:** Система должна позволять создавать новые мероприятия/консультации с указанием названия, описания, даты/времени и максимального лимита мест.
* **FR-1.2:** Система должна предоставлять публичный список всех доступных мероприятий (метод получения расписания).

## 2. Управление бронированием (Bookings)
* **FR-2.1:** Пользователь должен иметь возможность записаться на выбранное мероприятие, указав свои ФИО и контактные данные (Email).
* **FR-2.2:** Система должна автоматически проверять количество текущих записей на событие и отказывать в бронировании, если лимит мест (`max_slots`) исчерпан.
* **FR-2.3:** Система должна сохранять информацию о каждой успешной записи в реляционной базе данных с привязкой к конкретному мероприятию.
