# Система записи на консультации и мероприятия (EventBook)

Веб-приложение для автоматизированного бронирования слотов времени на консультации и мероприятия. Исключает ручное согласование расписания через чаты и предотвращает пересечения записей.

## Состав команды
* **Студент** — Аналитик, Архитектор, Разработчик, Тестировщик, DevOps (Соло-проект).

## Технологический стек
* **Backend:** Python 3.11, FastAPI, SQLAlchemy
* **Database:** SQLite / PostgreSQL
* **Containerization:** Docker, Docker Compose
